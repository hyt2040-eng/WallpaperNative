Multifolder Wallpapers

여러 이미지 폴더를 관리하고, 선택한 사진을 실제 Android 라이브 배경화면으로 전환하는 앱이야.

안내
이 GitHub Pages 버전은 설치 안내용 PWA야. 실제 라이브 배경화면 기능은 Android APK에 포함된 네이티브 WallpaperService가 담당해. 이 웹페이지를 PWA로 설치하는 것만으로는 시스템 배경화면을 변경할 수 없어.

APK는 GitHub 저장소의 Actions → Build Android APK → Artifacts에서 다운로드할 수 있어.
